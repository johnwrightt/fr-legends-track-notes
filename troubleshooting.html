Troubleshooting

Find the stage where the problem starts.

Random fixes can create more variables. Identify exactly when the problem appears, make one relevant change and test again.

Identify the failure stage

First decide whether the problem happens during installation, startup, loading, gameplay or after an update. The exact stage is more useful than a general description that the game “doesn't work.”

Installation issues

Check available storage, device compatibility and whether an older installation is conflicting with the current one. Avoid repeatedly changing versions without recording what happened.

Startup crashes

Restart the device and close unnecessary background applications. If the issue started after an update or configuration change, record that detail before making additional changes.

Loading or freezing

Test after a clean restart and check available storage. Note whether the freeze happens everywhere or only at a particular point. A problem tied to one location or action gives you a much narrower diagnostic target.

Problems after an update

Record the version and compare the behavior before and after the update. Version-specific problems are much easier to discuss when the exact version and device are known.

Keep a diagnosis record: device → version → exact symptom → when it happens → last relevant change → result of each test.

Use this order

  1. Restart the game and device.
  2. Check storage and basic compatibility.
  3. Identify the exact failure stage.
  4. Review the most recent relevant change.
  5. Test one fix at a time.
  6. Record the result before trying another fix.
