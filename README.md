# FR Legends Track Notes

Independent static HTML resource covering FR Legends driving, car selection, cornering, drifting, tuning, practice and troubleshooting.

## GitHub repository

`https://github.com/johnwrightt/fr-legends-track-notes`

## GitHub Pages URL

https://johnwrightt.github.io/fr-legends-track-notes

## Deployment

This is a plain HTML/CSS GitHub Pages site.

Upload the contents of this folder to the repository:

`fr-legends-track-notes`

Then enable GitHub Pages from the repository's Pages settings and publish from the main branch root.

## Canonical setup

Every HTML page has a self-referencing canonical URL using the GitHub Pages project URL.

The sitemap.xml and robots.txt use the same URL structure.

If the repository name is changed, update every canonical URL, sitemap.xml and robots.txt before indexing.

This is an independent FR Legends community resource and is not affiliated with or endorsed by the game developer.
